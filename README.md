# 🥐 Quitutes da Beth

Landing page para a **Quitutes da Beth**, cafeteria, padaria artesanal e empório em Conceição da Ibitipoca, Lima Duarte/MG.

🔗 **Site no ar:** https://jhonatasrodriss.github.io/Quitutes_da_Beth/

## Sobre o projeto

Site institucional de uma página, criado para apresentar o negócio, mostrar horário de funcionamento, localização e facilitar o contato direto com clientes via WhatsApp e Instagram.

## O que tem no site

- Seção sobre o negócio
- Galeria de fotos
- Localização com mapa incorporado
- Horário de funcionamento (com destaque automático para o dia atual)
- Contato via WhatsApp, Instagram e link único
- Botão flutuante de WhatsApp

## Stack

- HTML, CSS e JavaScript puro (sem frameworks)
- Hospedado com GitHub Pages

## Como rodar localmente

Basta abrir o arquivo `index.html` em qualquer navegador — não precisa de servidor ou instalação.
